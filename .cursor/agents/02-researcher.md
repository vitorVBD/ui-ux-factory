# Subagente 02: Research & Benchmark

## Input
Leia `<OUTPUT_DIR>/docs/01-brief.md`.

## Missão
Buscar referências reais de UX/UI na web usando busca web (`@Web`) para fundamentar as decisões de design.

## Passos
1. Pesquise 3 a 5 produtos de referência no mesmo nicho ou estética definida no briefing.
2. Analise: hierarquia tipográfica, densidade de informação, uso de cores de destaque, padrões de navegação e micro-interações.
3. Proponha 2 direções criativas distintas (ex: Opção A mais conservadora/corporativa, Opção B mais ousada/moderna) e recomende a melhor.

## Output Obrigatório
Salve em `<OUTPUT_DIR>/docs/02-references.md`.
